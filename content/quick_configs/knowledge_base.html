Help Center Account & Security Reset Your Password
Last edited by Sarah Chen
Updated 2 hours ago
1,284 views

This guide walks you through the process of resetting your account password. The process takes less than 5 minutes.

Before You Begin

Make sure you have access to the email address associated with your account. If you've lost access to that email, contact support directly.

Note: Password reset links expire after 24 hours. If your link has expired, simply request a new one.

Step-by-Step Instructions

  1. Navigate to the login page and click Forgot Password? below the sign-in form.
  2. Enter the email address associated with your account and click Send Reset Link.
  3. Check your inbox for an email with the subject "Reset your password".
  4. Click the reset link in the email. You'll be taken to a password creation page.
  5. Enter and confirm your new password. Requirements:
    • At least 8 characters
    • One uppercase letter
    • One number or special character
  6. Click Set New Password to save. You'll be logged in automatically.

Troubleshooting

If you don't receive the reset email within a few minutes:

  • Check your spam or junk folder
  • Verify you entered the correct email address
  • Add noreply@helpdesk.com to your allowed senders
  • Contact support if the issue persists

Froala Configuration for Knowledge Base

This demo uses the following Froala Editor configuration optimized for help center article authoring:

Why this configuration is chosen:

  • Structural Integrity: Prioritizes robust paragraphFormat choices to generate highly scannable, standardized FAQ and help articles that users can digest quickly.
  • Rich Utility: Gives writers access to table generation, perfect for comparing product features, troubleshooting steps, and pricing tiers in knowledge wikis.
  • Reference Capabilities: Features internal anchoring and link parameters suited for intricate table-of-contents routing across help centers without exposing users to naked URL navigation.
JavaScript Configuration 
new FroalaEditor('#froala-editor', {
  key: 'YOUR_LICENSE_KEY',
  pluginsEnabled: [
    'align', 'paragraphFormat', 'paragraphStyle',
    'lists', 'link', 'image',
    'table', 'fullscreen', 'charCounter',
    'wordCounter', 'quote', 'specialCharacters',
    'codeView', 'codeBeautifier'
  ],
  toolbarButtons: {
    'moreText': {
      'buttons': ['bold', 'italic', 'underline', 'strikeThrough', 'clearFormatting']
    },
    'moreParagraph': {
      'buttons': ['alignLeft', 'alignCenter', 'alignRight',
                  'formatOL', 'formatUL', 'paragraphFormat',
                  'outdent', 'indent', 'quote']
    },
    'moreRich': {
      'buttons': ['insertLink', 'insertImage', 'insertTable',
                  'specialCharacters', 'insertHR']
    },
    'moreMisc': {
      'buttons': ['undo', 'redo', 'fullscreen', 'html', 'selectAll']
    }
  },
  heightMin: 500,
  placeholderText: 'Write a helpful article...',
  charCounterCount: true,
  wordCounterMax: -1,
  paragraphFormat: {
    'N': 'Normal',
    'H1': 'Article Title',
    'H2': 'Section Heading',
    'H3': 'Subsection',
    'H4': 'Minor Heading',
    'PRE': 'Code Block'
  },
  imageEditButtons: ['imageReplace', 'imageAlign', 'imageCaption',
                     'imageRemove', 'imageAlt', 'imageSize'],
  imageInsertButtons: ['imageBack', '|', 'imageUpload', 'imageByURL'],
  imageAllowedTypes: ['jpeg', 'jpg', 'png', 'gif', 'svg'],
  tableEditButtons: ['tableHeader', 'tableRemove', '|', 'tableRows', 'tableColumns',
                     'tableStyle', '-', 'tableCells', 'tableCellBackground',
                     'tableCellVerticalAlign', 'tableCellHorizontalAlign'],
  linkEditButtons: ['linkOpen', 'linkEdit', 'linkRemove'],
  linkAlwaysBlank: false,
  toolbarSticky: true,
  toolbarStickyOffset: 0
});

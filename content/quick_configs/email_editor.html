Froala Configuration for Email

This demo uses the following Froala Editor configuration optimized for email composition:

Why this configuration is chosen:

  • Email Client Compatibility: Specifically utilizes htmlAllowedStyleProps to force formatting via inline CSS, bypassing external stylesheets which are frequently stripped out in desktop and web email clients.
  • Precise Structure: Retains table support, the gold-standard layout system for structurally-bound email newsletters over modern flexbox/grid.
  • Personalized Communication: Features emoticons and custom font controls, ensuring automated outreach feels personalized and authentic.
JavaScript Configuration 
new FroalaEditor('#froala-editor', {
  key: 'YOUR_LICENSE_KEY',
  pluginsEnabled: [
    'align', 'colors', 'fontSize', 'fontFamily',
    'paragraphFormat', 'lists', 'link', 'image',
    'table', 'emoticons', 'specialCharacters',
    'inlineStyle', 'lineHeight'
  ],
  toolbarButtons: {
    'moreText': {
      'buttons': ['bold', 'italic', 'underline',
                  'fontFamily', 'fontSize', 'textColor',
                  'backgroundColor', 'clearFormatting']
    },
    'moreParagraph': {
      'buttons': ['alignLeft', 'alignCenter', 'alignRight',
                  'formatOL', 'formatUL', 'outdent', 'indent',
                  'lineHeight']
    },
    'moreRich': {
      'buttons': ['insertLink', 'insertImage', 'insertTable',
                  'emoticons', 'specialCharacters', 'insertHR']
    },
    'moreMisc': {
      'buttons': ['undo', 'redo', 'html']
    }
  },
  heightMin: 350,
  placeholderText: 'Compose your email...',
  htmlAllowedStyleProps: ['font-family', 'font-size', 'background',
                          'color', 'text-align', 'padding', 'margin'],
  pastePlain: false,
  htmlRemoveTags: ['script', 'style'],
  imageEditButtons: ['imageReplace', 'imageAlign', 'imageRemove'],
  imageMaxSize: 5 * 1024 * 1024,
  imageDefaultWidth: 300,
  linkAlwaysBlank: true,
  linkAutoPrefix: 'https://'
});

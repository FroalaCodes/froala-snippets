# Froala Quick Starts — Real-World Use Cases

Ready-to-run Froala Editor configurations for 13 common real-world scenarios. Each file is a standalone HTML demo showing how to configure Froala for a specific use case — drop it into your project and adapt from there.

## Getting Started

Each file is self-contained. Open any HTML file directly in your browser — no build step or server required.

```bash
open blog_editor.html
```

To adapt a config for your project, click the **"View Config"** button inside any demo to see the exact Froala initialization options used, then copy them into your own setup.

## Shared Files

- `styles.css` — shared layout and design system styles used across all demos
- `config_utils.js` — modal and clipboard utilities for the "View Config" panel

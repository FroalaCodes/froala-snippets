Froala Configuration for Notes

This demo uses the following Froala Editor configuration optimized for note-taking apps:

Why this configuration is chosen:

  • Frictionless Workflows: Turns off visual char counters and uses familiar shortcut keys to mimic lightweight desktop note apps.
  • Rapid Persistence: Employs extremely fast automatic persistence looping via saveInterval to guarantee zero data loss during stream-of-consciousness journaling.
  • Clean Slate Pacing: Adjusts behavior using enter: FroalaEditor.ENTER_P, maintaining a comfortable vertical rhythm across highly segmented thoughts and isolated points.
JavaScript Configuration 
new FroalaEditor('#froala-editor', {
  key: 'YOUR_LICENSE_KEY',
  pluginsEnabled: [
    'align', 'colors', 'fontSize', 'paragraphFormat',
    'lists', 'link', 'image', 'table',
    'quote', 'emoticons', 'specialCharacters',
    'wordCounter', 'charCounter'
  ],
  toolbarButtons: {
    'moreText': {
      'buttons': ['bold', 'italic', 'underline', 'strikeThrough',
                  'fontSize', 'textColor', 'backgroundColor',
                  'clearFormatting']
    },
    'moreParagraph': {
      'buttons': ['formatOL', 'formatUL', 'paragraphFormat',
                  'alignLeft', 'alignCenter', 'alignRight',
                  'outdent', 'indent', 'quote']
    },
    'moreRich': {
      'buttons': ['insertLink', 'insertImage', 'insertTable',
                  'emoticons', 'insertHR']
    },
    'moreMisc': {
      'buttons': ['undo', 'redo', 'selectAll']
    }
  },
  saveInterval: 5000,
  saveParam: 'content',
  heightMin: 400,
  placeholderText: 'Start writing your note...',
  wordCounterMax: -1,
  charCounterCount: false,
  shortcutsEnabled: ['bold', 'italic', 'underline',
                     'strikeThrough', 'undo', 'redo'],
  imageEditButtons: ['imageReplace', 'imageAlign',
                     'imageRemove', 'imageAlt'],
  imageMaxSize: 5 * 1024 * 1024,
  imagePaste: true,
  linkAlwaysBlank: false,
  linkAutoPrefix: 'https://',
  pastePlain: false,
  quickInsertEnabled: false,
  enter: FroalaEditor.ENTER_P
});
